隐私政策

本政策描述维护者 huangmouren2023 的个人 rclone Google Drive 接入项目。更新日期：2026-10-14。

访问与使用 Google 数据

本项目通过 Google OAuth 请求账号持有人授权。授予完整 Drive 权限后，本机 rclone 可以列出文件及目录，读取内容，并根据使用者操作上传、修改、重命名、移动和删除文件。相关访问用于使用者对自己的 Google Drive 进行文件管理和媒体读取，不用于广告投放、建立用户画像或训练通用人工智能模型。

数据与凭据存储

OAuth 客户端资料、访问令牌和刷新令牌保存在使用者自己的设备配置中。按需缓存、待上传文件及运行日志也保存在自己的设备上；运行日志可能包含文件名、路径和错误信息。上传的文件与云端元数据由 Google Drive 存储。

这些本地数据的保留时间取决于实际 rclone 配置和使用者操作。读取缓存可按容量和时间清理；尚未完成上传的文件需要保留至上传完成。本站不承诺本地配置、日志或缓存自动永久删除。

传输与共享

rclone 为执行授权的文件操作与 Google 的 OAuth 和 Drive 服务通信。网站和代码托管由 GitHub 提供。维护者不出售 Google 用户数据，不把 Google Drive 文件或 OAuth 密钥上传到 GitHub Pages，也不通过本站将云盘内容提供给其他访客。

本项目对 Google API 数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

静态网站访问

本站不设置表单、站点分析脚本或应用自有追踪器，不接收云盘文件或 OAuth 密钥。GitHub Pages 作为托管服务可能按照其自身政策处理访问请求相关信息，具体见 GitHub 隐私声明。

撤销授权与删除

账号持有人可以在 Google 账号的第三方连接页面 撤销授权，并在自己的设备上删除对应凭据。停止使用后，可自行清理本地缓存和日志；清理前应确认待上传内容已处理。云端文件及回收站内容由账号持有人通过 Google Drive 管理。
