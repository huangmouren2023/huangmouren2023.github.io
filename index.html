GEM12 CloudDrive

使用 rclone 和 WinFsp，将本人授权的 Google Drive 作为 Windows 按需访问磁盘。

项目用途

本项目由 GitHub 用户 huangmouren2023 维护，供个人管理自己的 Google Drive 文件。计划支持在 Windows 中浏览、上传、下载、重命名、移动、删除文件，以及按需读取媒体。它不是公开提供的云存储服务。

Google Drive 接入使用 Google OAuth，由账号持有人决定是否授予权限。完整磁盘读写需要访问所授权 Google Drive 文件的权限。OAuth 客户端凭据和令牌保存在使用者自己的设备上。

本网站的作用

本站由 GitHub Pages 托管，仅提供项目说明和隐私政策。本站没有登录入口、上传表单、数据库或 OAuth 回调，不接收 Google Drive 文件、OAuth 客户端密钥或授权令牌。

实际文件操作发生在使用者自己的 rclone 程序与 Google Drive 之间。本项目不隶属于 Google、GitHub、rclone 或 WinFsp，也不代表这些项目提供服务。
